# Asset provenance

Every file in `pack/` is either **generated by code in this repository** or a
small geometry sidecar. No Mojang artwork is redistributed.

## How everything is produced

```bash
.venv/bin/python tools/gen_assets.py   # all PNGs + docs/preview sheets
python3 tools/build.py                 # validate + package
```

`tools/gen_assets.py` is the single source of truth for artwork. It defines the
palette, the crosshair shapes, the heart/hunger/armor masks, the nine-sliced
surfaces and the wordmark (a built-in 3x5 pixel font, no external font file).
The UI colours in `pack/ui/_global_variables.json` mirror the same palette.

## Geometry borrowed from vanilla (values only)

To make an override sit exactly where vanilla art sits, these *numbers* were
taken from the 1.19.50.2 files and encoded in `tools/build.py`:

* canvas sizes for every overridden sprite (checked automatically);
* nine-slice `nineslice_size` / `base_size` for `cell_image*`,
  `dialog_background_opaque`, `pause_screen_border`, `hud_tip_text_background`,
  `experiencebarempty`, `experiencebarfull`;
* the crosshair atlas cell rectangle `(0,0)-(15,15)`.

Numbers are facts about layout, not expression. The artwork inside those
rectangles is drawn from scratch.

## Preview sheets

`docs/preview/` holds review images generated from the pack files:
`hud_art.png` (contact sheet), `hud_mock.png` (hearts + hunger + hotbar
composited), `branding.png` (icon + wordmark), and `crosshair_*.png` (the four
available reticles). They are documentation, not pack content.

## Low fire

`tools/make_low_fire.py` transforms **your own** `fire_0.png` / `fire_1.png`
from your own installation. The result is written to `build/` and is never
committed. See [FEATURES.md](FEATURES.md#9-low-fire).

## Adding a texture

1. Add the drawing code to `tools/gen_assets.py`.
2. If it replaces a vanilla file, add its expected size to `VANILLA_SIZES` in
   `tools/build.py` and, for nine-sliced art, to `NINESLICE`.
3. Run `python3 tools/build.py` — it fails if the canvas size or sidecar does
   not match the vanilla contract.
